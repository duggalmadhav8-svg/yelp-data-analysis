# 🍽️ Yelp Business & Review Performance Analytics

An end-to-end data analytics project combining Python and SQLite to extract, query, and analyze restaurant performance metrics and user engagement patterns.

---

## 🚀 Project Overview
This project builds a relational database pipeline using SQLite and executes complex SQL queries alongside Python analysis. The goal is to evaluate restaurant ratings, user review sentiment trends, and geographical performance metrics.

---

## 🛠️ Tools & Technologies Used
* **SQLite / SQL:** Database schema creation, complex joins, filtering, and data extraction.
* **Python (Pandas):** Data post-processing and dataframe manipulation.
* **Matplotlib & Seaborn:** Visualizing review distributions and rating trends.
* **Jupyter Notebook:** Interactive development workflow.

---

## 📈 Key Analysis & Features
* **Database Management:** Built database schemas and executed structured SQL queries to filter high-engagement businesses.
* **Review & Rating Trends:** Analyzed customer feedback distribution across categories and locations.
* **User Engagement Patterns:** Evaluated review frequency versus average star ratings.
* **Visual Insights:** Plotted key performance indicators to compare restaurant performance across categories.

---

## 💡 Key Insights
* Highlighted key factors driving high customer ratings and review volume.
* Mapped category performance to identify top-tier dining sectors.
